
# C# Advanced – Practical Assignments

A collection of practical C# exercises and assignments focused on strengthening advanced programming concepts, problem-solving skills, and object-oriented programming fundamentals.

## Technologies

- C#
- .NET 8
- .NET Console Applications
- LINQ
- Collections
- Generics
- Delegates

## Topics Covered

### 1. Generics
- Generic classes and methods
- Generic constraints
- Reusable components
- Generic range implementation

### 2. Delegates and Functions
- Custom delegates
- Built-in delegates such as `Func`
- Passing methods as parameters
- Callback-based processing

### 3. Collections and LINQ
- Working with `List<T>`
- Filtering collections
- Extracting even numbers
- Reversing list elements
- Using LINQ queries

### 4. Algorithms and Problem Solving
- Sorting algorithms
- Swapping values
- Array manipulation
- Working with different data types

### 5. Object-Oriented Programming
- Classes and objects
- Properties
- Constructors
- Partial classes

## Repository Structure

The repository contains multiple folders for practical demonstrations and assignments covering different C# advanced topics.

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/MohamedBadawy23/C-Advanced.git
   ```

2. Open the solution or project using Visual Studio.

3. Restore dependencies if required.

4. Build and run the desired console application.

## Learning Objectives

- Improve C# programming skills.
- Understand advanced language features.
- Practice generic programming.
- Work with delegates and LINQ.
- Develop problem-solving abilities.
- Write reusable and maintainable code.
